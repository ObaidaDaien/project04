# Project04 — Exercise 00: Personal Portfolio

## Project Overview
This project is an authentic, responsive personal portfolio web application built completely from scratch using standard **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)**. In strict adherence to 42 Piscine guidelines, no external UI frameworks, templates, or libraries (such as Bootstrap, Tailwind, or jQuery) were used.
